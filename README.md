# Avaliação Automática de Redações no Modelo do Enem

Este repositório contém o aplicativo para iOS produzido no trabalho de conclusão de curso de Ciência da Computação, que consiste em um avaliador automático de redações no modelo do Enem. O trabalho buscou avaliar a viabilidade do fine-tuning de cinco modelos individuais baseados no BERTimbau, e sua implementação em um contexto on-device a partir do desenvolvimento de uma interface que permite o estudo das regras da prova de redação do Enem, a elaboração iterativa de redações e o acompanhamento do progresso do estudante.

O desenvolvimento dos modelos está disponível no repositório [/enem-automated-essay-scoring-models](https://github.com/exh-Auster/enem-automated-essay-scoring-models).
